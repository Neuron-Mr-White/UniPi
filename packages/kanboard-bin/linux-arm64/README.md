# @pi-unipi/kanboard-linux-arm64

The `unipi-kanboard` binary for **linux arm64** (rust target `aarch64-unknown-linux-musl`), installed automatically by [`@pi-unipi/kanboard`](../kanboard/README.md) as an optional dependency.

`bin/unipi-kanboard` is built by `.github/workflows/kanboard-binaries.yml` and is not committed to git.
