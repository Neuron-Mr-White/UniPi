# @pi-unipi/kanboard-win32-x64

The `unipi-kanboard` binary for **win32 x64** (rust target `x86_64-pc-windows-msvc`), installed automatically by [`@pi-unipi/kanboard`](../kanboard/README.md) as an optional dependency.

`bin/unipi-kanboard.exe` is built by `.github/workflows/kanboard-binaries.yml` and is not committed to git.
