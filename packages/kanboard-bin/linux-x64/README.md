# @pi-unipi/kanboard-linux-x64

The `unipi-kanboard` binary for **linux x64** (rust target `x86_64-unknown-linux-musl`), installed automatically by [`@pi-unipi/kanboard`](../kanboard/README.md) as an optional dependency.

`bin/unipi-kanboard` is built by `.github/workflows/kanboard-binaries.yml` and is not committed to git.
